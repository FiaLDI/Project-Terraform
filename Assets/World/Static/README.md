# World Static

This folder contains authored world spaces that are not primarily procedural.

## Current groups

- `Hub`
- `Boss`

## Role

Use this branch for fixed locations, handcrafted encounters, and other world content where authoring and scene composition matter more than seed-driven generation.

## Notes

There is already at least a small amount of local behavior here, such as `MoveOnTrigger.cs`, but the main value of this branch is assembled world content rather than large shared code systems.
